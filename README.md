# 📊 Olist E-Commerce Analytics Project

**Created by Sanidhya Mandliya**

An End-to-End Data Analytics and Business Intelligence Project built using **Python, Pandas, MySQL, SQL, and Power BI**.

This project transforms raw e-commerce data into meaningful business insights through data cleaning, data modeling, SQL analytics, summary table creation, and interactive dashboard development.

---

# 🚀 Project Overview

The Olist Brazilian E-Commerce dataset originally consisted of multiple interconnected raw tables containing customer, order, payment, review, product, and seller information.

The objective of this project was to transform raw operational data into a business intelligence solution capable of answering strategic business questions related to:

* Revenue Performance
* Customer Behavior
* Product Performance
* Seller Analysis
* Logistics Efficiency
* Delivery Performance

---

# 🔄 Project Workflow

## Stage 1: Data Cleaning & Transformation (Python)

The project began with 9 raw CSV files.

Using Python and Pandas:

* Data quality assessment was performed.
* Missing values were handled.
* Data inconsistencies were identified and corrected.
* Relevant datasets were merged together.
* Relationships between datasets were established.
* Raw data was transformed into an analysis-friendly structure.

After cleaning and integration, the original 9 datasets were consolidated into **3 primary analytical tables**.

This significantly reduced complexity and improved query performance for downstream analysis.

---

## Stage 2: Database Analytics (MySQL)

The transformed analytical tables were exported into MySQL.

Inside MySQL:

* Relationships between analytical entities were maintained.
* Data validation was performed.
* Business-oriented analysis was conducted.

More than **60+ SQL business queries** were written to extract actionable insights.
