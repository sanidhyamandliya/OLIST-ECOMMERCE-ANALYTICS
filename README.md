# Olist E-Commerce Analytics

End-to-End E-Commerce Analytics Project using Python, Pandas, MySQL and Power BI.

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to generate business insights related to revenue, customers, products, sellers, and logistics.

## Tools Used

- Python
- Pandas
- MySQL
- Power BI
- DAX

## Project Workflow

Data Cleaning (Python) → SQL Analysis (MySQL) → Dashboard Development (Power BI)

## Dashboard Modules

- Executive Board
- Revenue Analysis
- Product Analysis
- Logistics Analysis
